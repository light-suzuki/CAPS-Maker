# CAPS-Maker

2系統のFASTAまたは参照区間＋マルチサンプルVCFからCAPS/dCAPSマーカーを設計する、日本語GUI付きのオープンソースツールです。既存F/Rプライマーで標的を探したり、区間内に一定間隔・指定本数・全認識サイトのマーカーパネルを作成できます。[primerblast-oss](https://github.com/light-suzuki/primerblast-oss)の制限酵素切断シミュレーションとPrimer3/BLAST+処理を利用します。

**注意：** 本ソフトはin silico予測です。実際のPCR・制限酵素消化・ゲル検証を置き換えるものではありません。

## 機能

- 2つのFASTAファイルをアップロード、または配列を直接貼り付け
- グローバルアラインメントでSNP・InDelを検出
- 全制限酵素の探索、または指定酵素のみ（複数選択）
- A/Bのどちらが切断されるか、AA・AB・BBの断片長と切断部位数を一覧化
- 予測ゲルパターンから共優性・優性型・判別困難を判定（遺伝的優性とは異なる）
- 最小断片長、ゲル評価、推奨ゲル濃度、仮想ゲル（SVG）表示/保存
- Primer-BLASTモードではPCR産物長の下限・上限を指定、Primer3とBLAST+による特異性検証
- CSV（UTF-8 BOM付き、Excel対応）/TSV出力、プライマー発注表

## 必要条件

- Python 3.10以降、Git
- Primer-BLASTモードのみ、primer3_core・blastn、および作成済みのローカルBLAST nucleotide DB
- Streamlit、Biopython、pandas、primerblast-oss（requirements.txtに記載）

### Ubuntu / WSL2で起動

~~~bash
sudo apt update
sudo apt install -y python3-venv git primer3 ncbi-blast+

git clone https://github.com/light-suzuki/CAPS-Maker.git
cd CAPS-Maker
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt

streamlit run app.py
~~~

GUIが起動したらブラウザで http://localhost:8501 を開きます。Windows側のブラウザからWSL上のStreamlitに接続することもできます。

### Primer-BLASTモードの準備

ゲノムFASTAから、あらかじめBLAST DBを作成します。

~~~bash
makeblastdb -in reference_genome.fa -dbtype nucl -parse_seqids -out reference_db
~~~

GUIの「BLAST DBのローカルパス」に reference_db を指定してください。野生型/変異型の2配列とは別に、ゲノム全体での特異性確認用のDBが必要です。複数のDBを使うときは1行1パスで入力します。

## 使い方

1. 左右に配列A/Bを入力します（各1本、現行GUIでは8,000 bp以内）。
2. モードを選びます。
   - **制限酵素スキャン**：入力DNA配列の全長を仮想消化します。PCR産物の切断予測ではなく、候補酵素の探索に用います。
   - **Primer-BLAST付きマーカー設計**：検出したSNP・InDelを選び、PCR産物長の下限/上限、BLAST DB、Primer3候補数を指定します。両アレルで塩基配列が完全一致する共通プライマーだけを残して、予測PCR産物を切断解析します。
3. 対象酵素を「利用可能な全酵素」または「指定酵素」から選びます。
4. 「CAPSマーカーを探索」をクリックします。
5. 候補表をフィルタし、CSV/TSVおよびゲル画像（SVG）をダウンロードできます。

### 出力例

| 酵素 | 切断アレル | A断片(bp) | B断片(bp) | AB断片(bp) | マーカー型 |
|---|---|---|---|---|---|
| EcoRI | Aのみ | 300 + 200 | 500 | 500 + 300 + 200 | 共優性（3遺伝子型を識別） |

数値は説明用です。実際の出力には切断部位数、バンド分離、ゲル評価、Primer-BLASTの特異性情報も含まれます。

## マーカー型の意味

- 共優性：AA・AB・BBの予測バンドパターンを3つとも区別できる。
- 優性型：ホモ接合体同士は区別できても、ヘテロ接合体が一方のホモ接合体と同じに見える。
- 判別困難：ホモ接合体同士のゲルパターンも明確に区別できないなど、診断に不適。

これらは検出パターンの区別であり、変異の生物学的な優性/劣性とは異なります。分離の程度はゲルモデルで推定しており、実験上の分離を保証しません。

## 科学的な注意事項

- 完全消化と両アレルの増幅を仮定します。小断片は見えないことがあり、ゲル濃度、DNA量、酵素条件で変わります。
- 初版では両アレルに完全一致するプライマーのみを採用します。ミスマッチを許容するPCRは扱いません。
- BLASTがspecificと評価しても、検索が不完全なら特異性は保証されません。Bアレルの局所配列にプライマーが結合することと、Bゲノム全体の検索は別です。
- 仮想ゲルは標的PCR産物の消化モデルであり、オフターゲット産物由来のバンドは重ねていません。
- dCAPS（人工ミスマッチによる制限酵素認識部位作成）は、現行GUIでは未対応です。

## 参照ゲノム区間とマーカーパネル（新機能）

入出力は従来の2配列FASTAモードに加え、参照座標＋2系統VCFモードをサポートします。

| 入力 | 用途 |
|---|---|
| 2つのFASTA | 直接配列比較（各8,000 bp以下） |
| FASTA (.fai) またはBLAST DB＋染色体の開始/終了座標＋マルチサンプルVCF | 2系統の配列を参照区間から組み立てる |
| 既存のForward/Reverseプライマー | BLASTで一意のPCR標的区間を特定してCAPS解析 |

### 一括設計

- **全酵素サイト**: 区間内で差がある認識サイトを個別に探索。
- **一定間隔**: 10 kbごと、など指定間隔の候補から最大1件を採用。
- **指定本数**: 区間をN等分し各区画から候補を最大1件採用。マーカー候補がない区画は補充しない。
- **二段階実行**: 制限酵素サイトを先に発見して一覧化し、その後に選択した候補だけPrimer3＋BLAST+を実行。計算量と探索上限を管理する。

### dCAPS

「CAPSのみ」「CAPSが使えなければdCAPS（デフォルト）」「両方を探索」から選択できます。dCAPSではプライマーの人工ミスマッチを導入し、プライマー由来の塩基を含む実際のPCR産物について制限酵素消化を計算します。改変されたプライマーはゲノムBLASTで再評価します。

dCAPSでは認識サイトが増幅産物の端付近に形成され、小断片がゲルで見えない場合があります。必要に応じPAGE等の高分解能法で検証してください。

## 実験条件のプリセットとスコア

- 標準（2%アガロース）、小断片重視（3%）、長断片重視（1%）、自動、カスタム
- 100 bpラダー、1 kbラダー、手持ち製品のバンド長を入力するカスタムラダー
- 可視断片長の下限/上限、ゲル分離閾値、PCR産物長の下限/上限、Primer3候補数
- 共優性/優性型/判別困難をAA・AB・BBの**可視範囲内のバンドパターン**で評価
- 実験適合スコア・総合設計スコア（いずれも成功確率ではなく順位付け指標）
- CSV/TSV・プライマー発注CSV・AA/AB/BB予測ゲルSVG・失敗サイトCSV

## BLAST特異性の2つの基準

1. **厳密（デフォルト）**: 指定ゲノム中で参照標的産物が一意で、検索が完了し、オフターゲット産物を認めない。
2. **ゲル判別型**: オフターゲット産物を実配列から再構成し、選択した制限酵素による切断後の断片をAA・AB・BBのレーンに追加。それでも全遺伝子型を識別できるなら許容。

どちらも参照座標のアンカー、完全な検索、参照アセンブリの一致を要求します。BLAST検索が途中で打ち切られている、オフターゲットの配列が取得できない、設計用参照と最初のBLAST DBが一致しない場合は自動合格させません。評価の範囲は入力された参照ゲノムと探索設定に限られ、未登録系統や長大な副増幅産物の存在を否定するものではありません。

### 参照＋VCFの準備例（Ubuntu）

~~~bash
sudo apt install -y samtools tabix primer3 ncbi-blast+
samtools faidx reference.fa
makeblastdb -in reference.fa -dbtype nucl -parse_seqids -out reference_db
bgzip -c strains.vcf > strains.vcf.gz
tabix -p vcf strains.vcf.gz
~~~

VCFは参照と同一アセンブリで作成し、位置順に整列・正規化してください。**両方のサンプルでGTがホモ接合または同一アレルを示すことが必要**です。ヘテロ接合・欠損・重複変異・参照REF不一致・記号アレルは配列生成をやめてエラーを表示します。参照をBLAST DBから取り出す際はblastdbcmdを使用します。

## 注意事項

- 手入力FASTAは8 kbまで。区間一括設計は短いウィンドウごとに配列を取得します。
- 2系統の実ゲノムを持つ場合はVCFを介して系統差を指定します。VCF記録のない箇所は参照と同じと仮定します。
- dCAPSでは人工ミスマッチによるPCR効率低下の可能性があります。予測バンドと実測バンドの照合が必要です。
- 現時点のゲル評価は一般的なアガロースの分離範囲を使った経験則です。メーカー固有ラダーの強度、PAGE、酵素の購入費用、STAR活性や反応バッファーは未対応です。
