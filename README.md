# CAPS-Maker

2系統のFASTAまたは参照区間＋マルチサンプルVCFからCAPS/dCAPSマーカーを設計する、日本語GUI付きのオープンソースツールです。既存F/Rプライマーで標的を探したり、区間内に一定間隔・指定本数・全認識サイトのマーカーパネルを作成できます。[primerblast-oss](https://github.com/light-suzuki/primerblast-oss)の制限酵素切断シミュレーションとPrimer3/BLAST+処理を利用します。

**注意：** 本ソフトはin silico予測です。実際のPCR・制限酵素消化・ゲル検証を置き換えるものではありません。

## 機能

- 2つのFASTAファイルをアップロード、または配列を直接貼り付け
- グローバルアラインメントでSNP・InDelを検出
- 全制限酵素の探索、または指定酵素のみ（複数選択）
- A/Bのどちらが切断されるか、AA・AB・BBの断片長と切断部位数を一覧化
- 予測ゲルパターンから共優性・優性型・判別困難を判定（遺伝的優性とは異なる）
- 最小断片長、ゲル評価、推奨ゲル濃度、仮想ゲル（SVG）表示/保存
- Primer-BLASTモードではPCR産物長の下限・上限を指定、Primer3とBLAST+による特異性検証
- CSV（UTF-8 BOM付き、Excel対応）/TSV出力、プライマー発注表

## 必要条件

- Python 3.10以降、Git
- Primer-BLASTモードのみ、primer3_core・blastn、および作成済みのローカルBLAST nucleotide DB
- Streamlit、Biopython、pandas、primerblast-oss（requirements.txtに記載）

### Ubuntu / WSL2で起動

~~~bash
sudo apt update
sudo apt install -y python3-venv git primer3 ncbi-blast+

git clone https://github.com/light-suzuki/CAPS-Maker.git
cd CAPS-Maker
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt

streamlit run app.py
~~~

GUIが起動したらブラウザで http://localhost:8501 を開きます。Windows側のブラウザからWSL上のStreamlitに接続することもできます。

### Primer-BLASTモードの準備

ゲノムFASTAから、あらかじめBLAST DBを作成します。

~~~bash
makeblastdb -in reference_genome.fa -dbtype nucl -parse_seqids -out reference_db
~~~

GUIの「BLAST DBのローカルパス」に reference_db を指定してください。野生型/変異型の2配列とは別に、ゲノム全体での特異性確認用のDBが必要です。複数のDBを使うときは1行1パスで入力します。

## 使い方

### 画面の構成

画面上部のバーに、選んでいる交配（系統A × 系統B）・対象集団・特異性DB・制限酵素・使える候補の数を常に表示します。主な画面は4つです。

- **マーカー設計**：解析方式（新規設計／既存プライマー／区間に一括配置／酵素の下調べ）を選び、左のパネルで交配と集団・特異性DB・場所・PCR条件を指定します。右の**実行**パネルは条件の要約と前提条件のチェックを表示し、スクロールしても追従します。結果は下に全幅で表示します。
- **ジェノタイピング**：集団と個体、記録するマーカー（範囲と密度で選択）、記録シートの作成、記入済みシートの確認、遺伝子型表の出力。
- **組換え・絞り込み**：記入済みシートから組換え個体と、マーカー間ごとの組換え数を表示します。
- **設定**：参照データ・DB、制限酵素、ゲル・判定条件。

**設計テンプレート**（マーカー設計の右上）から「単一座位・標準」「区間に配置・目標100 kb」「区間から最大10座位」「既存プライマーを確認」「戻し交雑（反復親A）用」「RIL・DH用」を適用できます。間隔・最小間隔・目標本数・探索半径・PCR産物長・酵素・ゲル条件を変更し、名前を付けて端末に保存できます。テンプレートには座標、DBパス、系統名、プライマー配列を含めません。100 kbや10座位は操作例の初期値であり、対象区間や集団に対する推奨値ではありません。

標的の入口は**場所**（染色体・開始・終了）と**既存プライマー**（F/R、5′→3′）です。既存プライマーモードは座標なしでも最初のBLAST DBから一意の産物を探せます。「場所も絞り込む」を選ぶと区間を制限できます。場所が複数・検索不完全なら自動採用しません。参照＋鎖に対して入力F/Rが逆の場合は順序を交換してBLASTを再実行し、出力の「プライマーの向き」に記録します。いずれも2系統の評価には参照と対応するVCFが必要です。

- **参照データ・DB**（設定）：登録名、種別（BLAST DB / 参照FASTA / VCF）、パスを入力して保存します。BLAST DBは接頭辞、FASTAは`.fai`、VCFは`.tbi`または`.csi`索引を確認して登録します。WindowsのドライブパスはWSL上では`/mnt/<drive>/...`に変換します。
- **制限酵素**（設定）：指定酵素・全酵素・保存した酵素セットを選べます。研究室の保有酵素を名前付きセットとして保存できます。
- **ゲル・判定条件**（設定）：ラダー・ゲル濃度・可視範囲・分離閾値。区別すべき遺伝子型の組は、マーカー設計の**対象集団**で選びます。

### 対象集団

| 対象集団 | 区別する遺伝子型 | 使えるマーカー型 |
|---|---|---|
| F2：AA・AB・BB | 3遺伝子型すべて | 共優性 |
| RIL・DH：AA・BB | 両ホモ | 共優性・優性型・2群識別 |
| BC→A：AA・AB | Aへの戻し交雑 | 共優性・優性型（ABとBBが同じ） |
| BC→B：AB・BB | Bへの戻し交雑 | 共優性・優性型（AAとABが同じ） |

結果表・結果CSV/TSV・発注表には、**両系統のプライマー結合と産物を確認し、参照座標付きの特異性評価を通り、対象集団の遺伝子型を判別できる候補のみ**を出します。厳密モードはAのみ、ゲル判別型ではAとBが対象です。C・Dや増幅未評価の酵素サイトは表示しません。配列全長の酵素探索だけでは検証済みPCRマーカーとして表示しません。条件を変更すると古い結果の表示を止め、再解析を求めます。

登録情報はリポジトリ外の`~/.codex/caps-maker/catalog.json`に保存します。`CAPS_MAKER_HOME`で保存フォルダーを変更できます。登録時の読み込み・索引確認と、解析時の参照同一性・特異性評価は別です。結果の「プライマーと予測ゲル」では、読み取ったバンドサイズを入れると一致する遺伝子型を表示します（ゲル画像の自動読み取りは行いません）。

### 配列と解析

1. 「設定」の「参照データ・DB」で参照FASTAまたはBLAST DB、対応する2系統のVCF、特異性検索用BLAST DBを登録します。
2. 「マーカー設計」で対象集団、登録データと2系統を選び、場所または既存F/Rプライマーを指定します。
3. 必要なら「設定」で対象酵素とゲル条件を変えます。
4. 新規設計・既存プライマーでは「CAPS候補を解析」を実行します。区間一括設計では間隔または本数を指定し、サイト探索とPrimer-BLASTを順に実行します。
5. 条件を満たす候補のCSV/TSV、発注表、ゲル画像（SVG）をダウンロードできます。

2つのFASTAを使う制限酵素探索は、入力DNA全長の仮想消化です。増幅・参照特異性が未評価なので、結果サマリーは確認できますが、使えるPCRマーカーの候補表には表示しません。

### ジェノタイピングと絞り込み

1. 「ジェノタイピング」で集団の種類と個体名（連番または貼り付け）を決めます。
2. 記録するマーカーを、範囲（染色体・開始・終了）と密度（一定間隔kb／指定本数／全座位）で選びます。区画ごとに1座位を選び、同じ座位の別プライマー候補は1座位として数えます。候補のない区画は空けたまま表示します。
3. 実験表と記録シートCSVを出力します。記録シートには遺伝子型ごとの予測バンド（判読キー）、親・F1コントロール行が入ります。記録はAA/AB/BB（A/H/B、0/1/2も可）、優性型ではA-（BB以外）・B-（AA以外）、欠測は空欄か「-」。
4. 記入済みのシートを読み込むと、コントロール不一致・判別できない記録・集団で起こりえない型・欠測・分離比（χ²、多重比較の補正なし）を確認できます。遺伝子型表はAA/AB/BBのワイド形式と、R/qtl形式（A/H/B/C/D、位置は物理位置Mb）で出力します。
5. 「組換え・絞り込み」で組換え個体と、マーカー間ごとの組換え数を確認します。表現型と照らして原因区間を狭めたら、次の回は狭めた区間を高密度にし、組換え個体だけを記録します。優性型の記録に隠れた組換えは数えません。

### 出力例

| 酵素 | 切断アレル | A断片(bp) | B断片(bp) | AB断片(bp) | マーカー型 |
|---|---|---|---|---|---|
| EcoRI | Aのみ | 300 + 200 | 500 | 500 + 300 + 200 | 共優性（3遺伝子型を識別） |

数値は説明用です。実際の出力には切断部位数、バンド分離、ゲル評価、Primer-BLASTの特異性情報も含まれます。

## マーカー型の意味

- 共優性：AA・AB・BBの予測バンドパターンを3つとも区別できる。
- 優性型：ホモ接合体同士は区別できても、ヘテロ接合体が一方のホモ接合体と同じに見える。
- 判別困難：ホモ接合体同士のゲルパターンも明確に区別できないなど、診断に不適。

これらは検出パターンの区別であり、変異の生物学的な優性/劣性とは異なります。分離の程度はゲルモデルで推定しており、実験上の分離を保証しません。

## 科学的な注意事項

- 完全消化と両アレルの増幅を仮定します。小断片は見えないことがあり、ゲル濃度、DNA量、酵素条件で変わります。
- 初版では両アレルに完全一致するプライマーのみを採用します。ミスマッチを許容するPCRは扱いません。
- BLASTがspecificと評価しても、検索が不完全なら特異性は保証されません。Bアレルの局所配列にプライマーが結合することと、Bゲノム全体の検索は別です。
- 仮想ゲル画像は標的PCR産物の消化モデルです。ゲル判別型の特異性判定では副産物の消化断片もレーンに加えて判別可否を計算しますが、画像には重ねていません。
- dCAPSは後述の「dCAPS」節の条件で設計します。人工ミスマッチによるPCR効率の低下は予測に含みません。

## 参照ゲノム区間とマーカーパネル（新機能）

入出力は従来の2配列FASTAモードに加え、参照座標＋2系統VCFモードをサポートします。

| 入力 | 用途 |
|---|---|
| 2つのFASTA | 直接配列比較（各8,000 bp以下） |
| FASTA (.fai) またはBLAST DB＋染色体の開始/終了座標＋マルチサンプルVCF | 2系統の配列を参照区間から組み立てる |
| 既存のForward/Reverseプライマー | BLASTで一意のPCR標的区間を特定してCAPS解析 |

### 一括設計

- **全酵素サイト**: 区間内で差がある認識サイトを個別に探索。同じ多型での酵素違いは別行に出るが、地図上のマーカー数は「座位」で数える。
- **一定間隔**: 10 kbごと、など指定間隔の区画から最大1座位を採用。
- **指定本数**: 区間をN等分し各区画から最大1座位を採用。マーカー候補がない区画は補充しない。
- **最小物理間隔**: 選ばれた座位どうしが指定距離未満にならないよう貪欲に選択（産物長・プライマー位置とは別の物理距離）。
- **探索半径**: 区画中心から指定距離内のサイトだけを候補にする。
- **選択の優先順位**: CAPS（人工ミスマッチなし）→ 指定スコア → 区画中心への近さ。
- **未カバー区画**: 候補がない／半径外／最小間隔で選べない区画を理由付きで表示・CSV出力し、区間マーカートラック（SVG）に赤帯で示す。
- **二段階実行**: 制限酵素サイトを先に発見して一覧化し、その後に選択した候補だけPrimer3＋BLAST+を実行。計算量と探索上限を管理する。
- **中断・再開**: ステップ2は座位ごとに結果を保持します。途中で他の操作をすると実行は止まりますが、再度ステップ2を押すと計算済みの座位を飛ばして続きから計算し、途中結果も表示・出力できます。失敗した座位は理由付きで「未成功サイトCSV」に出ます。

### 既存プライマー

参照区間＋VCFモードでは、まずプライマーをBLASTで検索し、指定区間内に標的産物が**ちょうど1つ**あることを消化前に確認します。区間内に0件・複数件、または探索が不完全な場合は解析を止め、全DBで予測された全PCR産物（配列ID・座標・長さ・向き）を表で示します。成功時も、標的産物とその他の全産物の一覧を結果の上に表示します。

### dCAPS

「CAPSのみ」「CAPSが使えなければdCAPS（デフォルト）」「両方を探索」から選択できます。dCAPSではプライマーの人工ミスマッチを導入し、プライマー由来の塩基を含む実際のPCR産物について制限酵素消化を計算します。改変されたプライマーはゲノムBLASTで再評価します。

dCAPSでは認識サイトが増幅産物の端付近に形成され、小断片がゲルで見えない場合があります。必要に応じPAGE等の高分解能法で検証してください。

## 実験条件のプリセットとスコア

- 標準（2%アガロース）、小断片重視（3%）、長断片重視（1%）、自動、カスタム
- 100 bpラダー、1 kbラダー、手持ち製品のバンド長を入力するカスタムラダー
- 可視断片長の下限/上限、ゲル分離閾値、PCR産物長の下限/上限、Primer3候補数
- 共優性/優性型/判別困難をAA・AB・BBの**可視範囲内のバンドパターン**で評価
- 実験適合スコア・総合設計スコア（いずれも成功確率ではなく順位付け指標）
- CSV/TSV・プライマー発注CSV・AA/AB/BB予測ゲルSVG・失敗サイトCSV
- 参照座標BED（参照に載った産物のみ、BED6・0-based）
- 設定・出典JSON：解析条件、primer3/BLAST+/primerblast-ossのバージョン、判定モデルのバージョン、BLAST DBと参照FASTA/VCFの指紋（サイズ・更新時刻・先頭SHA-1）、結果行のSHA-256。同じ参照・同じ設定での再実行結果を `result_sha256` で照合できます。
- 「全酵素」選択時は、在庫がない・高価などの酵素を除外できます。

## BLAST特異性の2つの基準

1. **厳密（デフォルト）**: 指定ゲノム中で参照標的産物が一意で、検索が完了し、オフターゲット産物を認めない。
2. **ゲル判別型**: オフターゲット産物を実配列から再構成し、選択した制限酵素による切断後の断片をAA・AB・BBのレーンに追加。それでも全遺伝子型を識別できるなら許容。

内部評価は次の4区分を維持します。結果表には選択条件に適合するA、またはゲル判別型を選んだ場合のA/Bのみを表示し、C/Dは採用しません。総合設計スコアもA合格をB合格より上位にします。

| 区分 | 意味 |
|---|---|
| A 厳密合格 | 全DBで探索完了、標的産物が一意、副産物なし |
| B ゲル判別で合格 | 副産物はあるが、実配列から再構成・消化しても AA/AB/BB を識別できる（ゲル判別型を選んだ場合のみ） |
| C 不合格 | 副産物あり（厳密）、副産物とバンドが重なる、または探索完了なのに標的産物が0件/複数件 |
| D 判定不能 | BLAST探索の打ち切り、参照座標なし、設計参照とDBの不一致。自動では合格にしない |

どちらも参照座標のアンカー、完全な検索、参照アセンブリの一致を要求します。BLAST検索が途中で打ち切られている、オフターゲットの配列が取得できない、設計用参照と最初のBLAST DBが一致しない場合は自動合格させません。評価の範囲は入力された参照ゲノムと探索設定に限られ、未登録系統や長大な副増幅産物の存在を否定するものではありません。

### 参照＋VCFの準備例（Ubuntu）

~~~bash
sudo apt install -y samtools tabix primer3 ncbi-blast+
samtools faidx reference.fa
makeblastdb -in reference.fa -dbtype nucl -parse_seqids -out reference_db
bgzip -c strains.vcf > strains.vcf.gz
tabix -p vcf strains.vcf.gz
~~~

VCFは参照と同一アセンブリで作成し、位置順に整列・正規化してください。**両方のサンプルでGTがホモ接合または同一アレルを示すことが必要**です。ヘテロ接合・欠損・重複変異・参照REF不一致・記号アレルは配列生成をやめてエラーを表示します。参照をBLAST DBから取り出す際はblastdbcmdを使用します。

## 注意事項

- 手入力FASTAは8 kbまで。区間一括設計は短いウィンドウごとに配列を取得します。
- 2系統の実ゲノムを持つ場合はVCFを介して系統差を指定します。VCF記録のない箇所は参照と同じと仮定します。
- dCAPSでは人工ミスマッチによるPCR効率低下の可能性があります。予測バンドと実測バンドの照合が必要です。
