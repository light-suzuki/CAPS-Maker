# Public repository boundary

- Keep the application usable across organisms and research groups. Do not add
  personal project assumptions, real local paths, private sample names or
  unpublished locus identifiers as defaults, examples or fixtures.
- Commit only synthetic fixtures or data with a documented public source.
  Keep private genomes, variants, reference catalogs and experiment outputs
  outside this repository or under ignored local directories.
- Keep local reference paths in local configuration. Provenance exports may
  contain paths, sample identifiers and input metadata; retain local originals
  and inspect any copy intended for publication, including screenshots.
- Before publishing, inspect staged changes and new files for those fields.
  Do not publish local catalogs, raw reports, credentials or user data.
- Preserve measurements and scientific provenance when preparing a separate
  public example; use synthetic data rather than replacing actual observations.
